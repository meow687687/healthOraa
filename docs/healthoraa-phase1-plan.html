Risks to manage

These are known from the current code and scope; the full detailed plan includes verification commands and ownership.

Late payment capture

Razorpay Orders have no local-reservation expiry field. Late captures now request an idempotent full refund and update from refund webhooks; temporary API failures retry, while permanent failures stay in the admin queue. Keep live keys off until sandbox proof and an operator are in place.

Unapproved imagery

Do not invent practitioner credentials, testimonials, outcomes, or product photography. Request approved brand and product assets.

Fresh database drift

Require a clean migration reset and type generation before calling the demo repeatable. Existing local database state is not enough.

Portal first load

Practitioner largest chunk is 433.21 kB (122.50 kB gzip). Admin emits a 698.02 kB initial chunk and a 378.99 kB chart chunk. Measure route startup, set a budget, and defer/split if it is missed.
